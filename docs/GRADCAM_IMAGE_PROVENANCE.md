## 2. Selection Methodology and Strict Separation

- **Data Partition:** Drawn exclusively from the **VALIDATION** partition (never from the held-out TEST partition).
- **Selection Determinism:** Selected prior to model inference using a deterministic SHA-256 ranking of `seed|source_path` with seed `H3_gradcam_validation_seed42_v1`.
- **Group Independence:** The six selected images originate from **six distinct reconstructed source-image groups** (ensuring no shared glass-slide source between examples).
- **Diagnostic Distribution:** Exactly 2 cases per class (`lung_aca`: 2, `lung_n`: 2, `lung_scc`: 2).
- Complete selection metadata is preserved in [`results/H_GradCAM_H3_validation_seed42/validation_gradcam_examples.csv`](../results/H_GradCAM_H3_validation_seed42/validation_gradcam_examples.csv).

## 3. Gradient-Weighted Class Activation Implementation

In the H3 pooled-feature concatenation architecture, Grad-CAM is formulated across two distinct convolutional backbones simultaneously:

1. **MobileNetV2 Branch:**
   - Target convolutional layer: `out_relu` (output shape $7 \times 7 \times 1280$).
   - Feature characteristics: High spatial responsiveness to fine edges, cell membranes, and nuclear chromatin textures.
2. **EfficientNetB0 Branch:**
   - Target convolutional layer: `top_activation` (output shape $7 \times 7 \times 1280$).
   - Feature characteristics: Broad contextual responsiveness to glandular architecture, tissue patterns, and multicellular aggregates.
3. **Attribution Target:**
   - Both branches are differentiated against the **exact same predicted-class pre-softmax logit** ($z_c$) in the trained H3 fusion classification head (`fusion_class_scores`).
   - $\alpha_k^c = \frac{1}{Z} \sum_{i} \sum_{j} \frac{\partial z_c}{\partial A_{i,j}^k}$
   - $L_{\text{Grad-CAM}}^c = \text{ReLU}\left(\sum_{k} \alpha_k^c A^k\right)$
4. **Overlay Normalization:**
   - Activations are normalized independently to $[0, 1]$ via min-max scaling, resized bilinearly to $224 \times 224$, and mapped to RGB using the standard Jet colormap with $\alpha = 0.4$ transparency.

## 4. Methodological and Clinical Interpretation Caveats

- **Relative Normalization:** Because heatmap intensities are normalized independently within each branch, color intensity reflects relative spatial prominence within that backbone, **not** quantitative contribution weighting between MobileNetV2 and EfficientNetB0.
- **Coarse Spatial Resolution:** The $7 \times 7$ feature activation grid maps to approximately $32 \times 32$ pixel receptive fields on the $224 \times 224$ input image. It provides coarse regional saliency, not precise cellular or sub-cellular semantic segmentation.
- **Not Diagnostic Ground Truth:** Saliency highlights correlation with the neural network's internal features. It must not be interpreted as definitive clinical evidence of malignant transformation or pathological margins.
